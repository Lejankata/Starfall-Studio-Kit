# Contributing

Thanks for helping improve Starfall Studio Kit.

## Before proposing code

1. Check for an existing issue covering the same problem.
2. Describe the issue and the behavior you observed.
3. For bug fixes, include precise reproduction steps and Output logs from Roblox Studio.
4. Keep changes small and focused where possible.
5. Run `python tools/verify.py` before opening a pull request.
6. Test changed gameplay in Roblox Studio and accurately check the items you completed in `docs/TESTING.md`.

## Pull requests

- Explain why the change is needed.
- Summarize how the change affects the server's trusted state, the client, or both.
- Attach screenshots for UI changes.
- Include your Roblox Studio test outcomes; label untested work explicitly.
- Avoid large unlicensed third-party assets.

There is no financial reward for contributions, and the maintainers do not promise Anthropic program eligibility to contributors.
