# Roadmap

This roadmap describes **ideas**, not completed features.

## 0.2
- Confirm Studio tests on Windows and macOS, fix reported runtime errors.
- Introduce accessible high-contrast controls and optional reduced motion.
- Add targeted tutorial hints for brand-new players.
- Improve the world layout with original meshes.

## 0.3
- Move gameplay definitions into ModuleScripts with clear service interfaces.
- Add automated Luau unit tests using a test runner and Roblox-compatible mocks.
- Introduce per-player crystals as an opt-in mode.
- Add localized strings for menus and prompts.

## 0.4
- Add session-locking persistence and structured error metrics.
- Add admin-only test commands in private Studio sessions.
- Implement save-data migrations with versioned schemas.
- Benchmark server load with 20+ simultaneous players.

## Not planned
- Gambling mechanics or paid randomized rewards.
- Copying existing Roblox game brands, assets, maps, or characters.
- Fabricated popularity claims or fake player statistics.

## After v2

- Independently playtest new pet/world saving and server-authoritative purchases.
- Add accessibility improvements for keyboard/controller users.
- Add server-side performance profiling and object pooling as the map grows.
- Consider session locking before public release or higher-value economy features.
