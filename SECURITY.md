# Reporting a security issue

If a vulnerability affects a published game or exposes personal data, **do not post an exploit publicly**.

Use the repository's GitHub **Security > Report a vulnerability** feature when available. If the repository owner has not enabled private vulnerability reports, ask them to enable the feature before sharing sensitive details.

This project is a learning starter without payments or player trading. See [docs/SECURITY.md](docs/SECURITY.md) for its threat model.
